what's new

every release of dusk bot, newest first.

0.2.32

27 november 2026

Fresh chats, and a cloud that wakes itself

everywhere

  • Type /new for a clean chat, or /compact to shorten a long one.
  • Phone alerts arrive, and your phone tells you if they can't.
  • Attach a .zip and your bot reads every file in it.
  • iPhone photos arrive as pictures, and code files keep their names.
  • After an update, the app shows what's new, like this.
  • A chat you leave for 6 hours is summed up before you come back.
  • Every release lists all it changed on dusk.bot/changelog. #353
  • Screenshots a bot takes while it works stay in its steps, not in your chat.
  • In a long chat, the message you are reading stays put while older ones load.
  • A tool failure card no longer shows when the tool actually worked.

desktop app

  • A sleeping dusk cloud says Waking and opens on its own.
  • While it works, your bot's mascot glances to show what it is doing.
  • Getting started is quicker: AIs already on this computer connect by themselves.
  • A chat's own notes sit in the middle, like bots talking to each other.
  • The window is simpler, with no row of places down the side.
  • Connect an AI always shows all eight AIs to pick from.
  • Google Antigravity signs in more reliably and says plainly what to fix when it can't.
  • The line under a working bot says what it is doing right away.
  • When a model is turned down, the message says to pick another one.
  • On Windows, Codex installs itself even without Node.js.
  • Linking a server no longer fails with a missing file error.
  • A message's menu is no longer cut off at the edge of the chat.
  • App updates finish on slow or dropping connections, and a Mac app on another server's page updates itself.
  • On Windows, a Windows Hello check that did not pass before a QR code says so, with Try again.

phone app

  • The phone can pair by scanning the QR code a server shows in its browser sign-in.
  • The phone's QR scanner always closes.

your own server

  • Ask one bot to forget something and your other bots forget it too.
  • Your dusk cloud keeps Codex up to date by itself.
  • A dusk cloud brought back from its archive starts up again.
  • A Telegram watch passes on every message, long ones in parts.
  • Claude stays signed in when its login renews.
  • ChatGPT, Grok and Kimi stay signed in when you use more than one computer.
  • If ChatGPT turns down a model, Codex uses its default one instead of stopping.
  • A new model picked for a Hermes bot works from the next message.
  • Your bot says a quick first line again while it works, so you hear back in seconds.
  • A helper's working notes stay out of the chat; you get your bot's own reply.
  • An AI you added with a key gets tested too, so bots no longer get stuck on the free backup.
  • Script checks waiting for your OK can be allowed again, instead of showing Expired at once.
  • Your bot no longer makes up settings that dusk bot does not have.
  • A message sent just as a bot starts gets one answer, not two.
  • A bot that sends something through a connected app can say it is done.
  • Fewer routines fail: a briefing with nothing new stays quiet instead of counting as a failure.
  • A routine run that fails for a passing reason quietly tries once more.
  • Routine reports keep symbols like € and emoji intact. #334 #335
  • Bots can use this computer's shell on a server you run with duskbot serve, and find files anywhere in your home folder.
  • Busy or rate limited AIs are retried for longer before a reply fails.

command line

  • duskbot update says when a newer server is out and updates it for you.

0.2.31

25 november 2026

Bots that sound like a person

everywhere

  • Everyday replies come as one to three short messages that open with the result, with no narrated plan.
  • Bots read the room: clean sentences for polished people, short and warm for everyone else, and they play along with a joke once.
  • "Keep an eye on my day" is on by default once apps are connected; pause or delete the routine to turn it off.

desktop app

  • A new bot says hi with what's on your plate instead of asking what you'd like.

phone app

  • Android app 1.2.12 is in this release; it registers for push notifications as soon as it pairs. #353

your own server

  • An app you connect or reconnect mid-chat works on the next message, including on Antigravity and the other ACP engines. #208
  • Bots find the right tool faster when many apps are connected.
  • In a group chat, a bot keeps each room's facts to that room.
  • Teammate bots no longer get stuck re-sending work they already sent.
  • A sleeping dusk cloud wakes more reliably.

0.2.30

25 november 2026

Chained routines and smoother phones

everywhere

  • Routines can follow each other: one can read another's latest report, or run as soon as the one it follows finishes.
  • When a chat engine runs out of credit, rate-limits or goes down, the turn carries on with the bot's next engine.
  • Bots can read each other's chats, read only, on by default; turn it off under Permissions.

desktop app

  • A reply carries the full message it replies to.
  • Quitting on a Mac no longer hangs on a blank window when the direct link to a server fails. #209
  • A message you send a bot from Telegram or Discord no longer turns that thread into the bot's main chat. #207
  • Cmd+= (Ctrl+= on Windows and Linux) makes text bigger, beside Cmd+- and Cmd+0. #200
  • The Mac app no longer waits for its rollout turn when its own server already runs the newer version. #210
  • Long chats with many hidden tool steps no longer bounce on "Show later messages". #205 #213
  • Antigravity's added Google accounts start Google sign-in and never show Claude's sign-in. #211 #212
  • Long chats open and scroll back faster, and the app downloads less on first load.
  • A follow-up typed while the server is unreachable stays on screen and sends once it is back. #293
  • Lists and quotes carry on while you type in the message box. #235

phone app

  • Android: notifications through a Messages channel, the microphone for voice, and plain http only to local addresses.
  • Smoother motion when opening and leaving a chat on the phone.

your own server

  • A script-only routine runs a command on its schedule and posts what it prints, with no AI turn. #298
  • A routine can set how late a missed run may still start, including never. #305
  • A self-hosted server can tell time in its owner's time zone (DUSK_ADOPT_TIME_ZONE=1), like a dusk cloud. #306
  • A bot can mark its own routine run as failed when the data it needs is broken. #307
  • Script checks on a server installed without install.sh explain the AppArmor fix instead of asking for a reinstall. #308
  • A script check that wakes the AI uses the routine's own time limit, not a fixed 60 seconds. #309
  • Phone pairing works with servers linked through the second link node. #202
