dusk bot/glossary

what is agent memory?

agent memory is information an ai keeps for later tasks, even after you start a new conversation. a packing preference can save you from repeating yourself on every trip.

by the dusk bot team · checked 20 november 2026 · how we made this

a detail from a single journey can also become a bad habit if the agent treats it as permanent.

in one line

agent memory carries selected facts or preferences from an earlier exchange into a later one.

an example

daphne usually packs walking shoes but needs dress shoes for a wedding trip. imagine her next packing list includes dress shoes for a muddy campsite. the agent remembered a true detail and used it in the wrong place. a better note ties the shoes to the wedding and expires after the trip.

separate a habit from an exception

ask whether the detail will still help on an ordinary day next month. a preference for a short packing list probably will. the dress code for a particular dinner belongs with that dinner.

to test the distinction, start a fresh chat and ask for a campsite list. if the dress shoes turn up, inspect the saved preference.

where dusk bot keeps the note

open the bot's memory settings to read or edit its notes. each bot has its own memory. its threads share that memory, and a note can have an end date.12

a bot can pick up facts from your own messages. look in settings under about me for facts added by your bots. every bot gets the about me details, so reserve that space for preferences that travel well.1

when a saved note is the wrong tool

keep a one-off detail in the task if it would confuse the next one. dusk bot is more setup than you need for a single packing list. if you already use it and want to stop using saved notes, switch off let this bot use memory. the files stay on disk. turning memory off doesn't erase them.1

questions

will switching the bot's ai clear its memory?

no. the bot keeps its chats, files and memory when you change its model. edit the note itself to correct a mistake.2

does my bot learn preferences from group chat?

dusk bots learn from your own messages to them. they don't learn from group chats. tell the bot directly when a detail should carry forward.1
