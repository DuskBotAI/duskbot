dusk bot/glossary

what is a browser agent?

a browser agent uses a web browser to carry out a task for you. it can follow links, choose a filter and read the results that appear.

by the dusk bot team · checked 20 november 2026 · how we made this

this matters when the answer depends on choices a search result can't show, like which beginner tennis lessons still have space on a particular saturday.

in one line

a browser agent is an ai that interacts with websites and uses what it finds to choose its next step.

an example

cecil wants a saturday tennis lesson that includes a loan racket. in this example, the booking site resets the date when someone switches venues. a result worth keeping names the venue, the saturday date and the class type shown together. a list copied from the default weekday view is useless.

what should come back from a search?

ask for the evidence you would use to choose a session. a class title alone tells cecil little. ask whether the listing includes racket hire or asks players to bring their own. if the listing leaves that open, keep it as a question for the coach.

give the agent a stopping point. for this search, the class listing is far enough. reserving a place or filling in attendee details goes beyond finding options.

when the site asks you to sign in

in dusk bot, you can take over the browser for a sign-in. watch through screen, choose take control, then hand control back. you enter the password yourself. the bot stays signed in and never sees the password.1

use a public listing without signing in when it already shows the answer.

when a bookmark will do

skip dusk bot for a timetable you can read at a glance. a browser agent makes more sense when answering the question means opening several views. even then, look at the current listing before heading out. someone else may have taken the last place.

questions

how is a browser agent different from web search?

search can find the club's site. a browser agent can work through its date and location controls to reach the particular listing you need.

does the agent need access to my other tabs?

no. a dusk bot can use its own browser and desktop, separate from yours. hand it the club's web address to start.1
