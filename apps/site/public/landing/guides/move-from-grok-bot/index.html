how to export your grok bot setup

ask your grok bot to write down its setup as a file. there is no export button for the whole bot.1 in dusk bot, open settings → import → Move from Grok Bot.

by the dusk bot team · checked 20 november 2026 · how we made this

paste or drop the file. you can see the bot’s name and counts for skills, routines and memories before you import anything.

save files you still need to open

save the bot’s work separately from its instructions. if a bot made a spreadsheet you need next month, download the spreadsheet. grok offers individual file downloads and download all. for a call, you can export its transcript or recording.1

share → create a copy publishes a bot template by link. it includes identity, skills and routines. it leaves out history and memory. to keep the preferences you taught the bot, follow the import steps.1

read the preview before accepting

look for the bot’s name first, then the counts. a skill holds instructions you reuse. a routine says when a workflow should run. memories include preferences and rules you have taught the bot. the preview counts each kind separately.12

if the bot has a regular job and the preview shows no routines, stop there. compare the file with the schedule in grok. for a missing preference, ask the original bot what it remembers. grok lets you inspect its memory in chat.1

the preview counts skills, routines and memories. it makes no promise about chat history, browser sessions or sign-ins. keep access to anything you still need to inspect.

give each routine a single home during the trial week

keep both apps for a week, with each schedule active in just one. pick a routine whose result you can recognize. turn it off in grok before you turn it on in dusk. look at the next run on the dusk routine card.3

for a desktop trial, leave dusk open and the computer awake when the job is due. look for the result in run history under automations. if you need the old schedule back, pause the dusk routine first.3

treat the week as your own comparison period. keeping both services may cost money. the side-by-side comparison covers phone access, storage and the monthly bill.

cancel the plan without deleting cursor

decide whether you still use the rest of the subscription. grok bot comes with qualifying x or legacy plans. there is no separate bot subscription to cancel. if you still want cursor, find the plan that pays for it before changing billing.45

account deletion removes bots, chats, computers and connected apps. deleting the grok bot service also deletes your whole cursor account. cursor purges the data within 30 days. do not use deletion as a shortcut to stopping renewal.4

if continuing with grok looks easier than rebuilding a workflow, keep it. the grok bot alternatives compare what you can keep on each service.

move a bot from its first file to its first run

  1. pick a bot you know well. note a skill, a schedule and a preference you expect to find again.
  2. open the importer. in dusk settings, choose import, then Move from Grok Bot. the import needs no sign-in and makes no network call.
  3. message that bot in grok. ask it to write its setup to a file for the move. work with one bot at a time so the file and preview belong together.
  4. paste or drop the setup file into dusk. read the name and preview counts. import when they match what you expect.
  5. hand over the schedules individually. turn a routine off in grok, then on in dusk. look for its first result before retiring the old setup.
  6. finish the trial week before changing the bill. keep the files you need and confirm which subscription you would be canceling.45

questions

can i export all my grok bot conversations?

the grok bot docs list no full conversation export. downloading files or exporting a call transcript saves those items. a shared bot template omits conversation history. keep the original account available if you still need old chats.1

does a week of testing mean my grok trial will renew?

the offer matters. the one-time cursor account credit expires within seven days and never converts. an ios app store trial converts to a paid apple subscription. read the offer you accepted before choosing the date to cancel.4
