a todoist bot for deciding what gets tomorrow morning

pick tomorrow's first task before you close today's list. a todoist bot can read overdue tasks alongside tomorrow's commitments and bring you a shortlist in dusk chat.

by the dusk bot team · checked 20 november 2026 · how we made this

tell it which deadlines are firm. it can also pull errands for your next trip and find the work you actually finished this week.

what a bot can do in Todoist

use the right list for the question. active tasks answer what's left. completed tasks answer what got done. name the project or label exactly as it appears in your account so another project with similar work stays out of the plan.

actiondusk bot treats it aswhat you would use it for
Get All Tasksreadfind incomplete tasks due tomorrow or already overdue
Get Task (API v1)readopen an active task by id before deciding whether it can wait
List Labelsreadfind the actual errand label you use
List Sectionsreadsee how you divide a project before grouping its work
Get Completed Tasks By Completion Datereadfind the tasks you finished during the week
Update Taskchangechange a due date after you choose the task and new date

composio, the connection service behind dusk bot's apps, lists 84 Todoist actions (version 20261116_00, read 20 november 20263). dusk bot treats 39 as reads, 2 as sends and 43 as changes.

only actions starting with a read word (get, list, search) count as reads, so a read-only bot can't call the rest. a send reaches people or moves money, like create comment (api v1), and waits for your Allow unless you set a daily amount.

connect Todoist

  1. open Connected apps in the sidebar.
  2. pick Todoist and sign in on Todoist's own page, so your password goes to them and never to a bot.
  3. choose which bots may use it, and whether each may only read or may also change things. your bookkeeper doesn't need your Todoist.
  4. ask in plain words. reading and drafting happen freely; sending asks you first.

tell the bot which dates you promised someone else. a due date alone doesn't explain the cost of moving it. connect todoist read only, then name the projects and labels you use. ask for one evening plan in chat before turning it into a routine.

routines to copy

reserve one clear decision for each message. an evening plan should tell you where to start. a shopping trip needs a list you can use away from your desk. your weekly recap needs completion dates.

tomorrow's first task

every weekday at 6 pm, read my overdue tasks and tasks due tomorrow. ask me which deadlines are firm at setup. suggest one task to start with and tell me why. separate the remaining commitments from things i could move. keep all dates and priorities as they are.

weekdays at 18:00 · a first task and a shortlist of dates to reconsider

errands before the trip

every saturday at 9, find my open tasks with the errands label. group them by shop or location only when the task says where to go. put missing locations under decide before leaving. include anything already overdue. leave the tasks open.

saturdays at 09:00 · a trip list grouped by the places you actually need to visit

finished this week

each friday at 4, read tasks i completed since monday in my work project. group them by section. include tasks with no due date if i completed them this week. give me a short recap here and leave unrelated personal tasks out.

fridays at 16:00 · finished work for a weekly update, including unscheduled tasks

what it asks you first

a plan in chat leaves your due dates intact. changing a task's date or priority is a write. it can run without an approval card. keep the planner read only. for a bot that can reschedule, give it the instruction “ask me before you change anything.”

what it cannot do

  • find finished work in the active task listing. it returns incomplete tasks. asking for completed items through that filter fails.
  • pull a whole year in one completion-date request. the completion action limits a window to about three months. review shorter periods for a longer recap.
  • move a task to another project with the update action. that action changes task properties. leave project moves out of a date-editing routine.

make a shortlist you can finish

give the bot the morning you actually have. if you only have a short stretch before an appointment, say so in chat. ask for one small first step where a task looks too large. if you already know the next task, opening it yourself is faster.

questions

does a todoist bot need write access to filter overdue tasks?

no. the active task listing accepts an overdue filter. allow that read action for the evening plan. the separate action named filter tasks counts as a change in dusk.

can i recap tasks that had no deadline?

yes. ask for completion dates. set the project and time window. using the original due date would leave out precisely the unscheduled work you're trying to remember.
